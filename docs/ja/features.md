## 既知の制限

- 状態はメモリ内。再起動でセッション、キュー、retained が失われます。
- クラスタ転送はベストエフォート、共有サブスクリプションはノード単位。
- 永続化、拡張認証、送信エイリアス、レート制限、ブリッジ、プラグイン SDK は未実装。
