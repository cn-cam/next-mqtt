## 拡張性

NextMQTT 0.1.x が提供するのは拡張**インターフェース**であり、プラグイン ABI
ではありません。他の MQTT ブローカー向けにビルドされたプラグインパッケージは
読み込まれず、互換性もサポートもありません。

| 拡張ポイント | インターフェース | 用途 |
| --- | --- | --- |
| クライアント認証 | `IClientAuthenticator` | ユーザー名/パスワードと API キー検証の置換・拡張 |
| トピック認可 | `ITopicAuthorizer` | クライアント単位で pub/sub を許可・拒否 |
| クラスタルーティング | `IClusterRouter` | HTTP 転送方式の置換 |

いずれも DI から解決されるため、拡張はソース変更と再ビルドで行います。追加の
ランタイムも独自の設定スキーマも不要です。プロセス外の連携にはバージョン付き
REST API（`/api/v1`）とクラスタエンドポイント（`/internal/cluster`）を使います。
独自の拡張ホストはロードマップ上にあり、実装前に ADR が必要です
（[ADR 0005](/adr/0005-extension-interfaces.md)）。

## 既知の制限

- セッション、キュー、購読はメモリ内で再起動時に失われます。retained はファイルログで保持できます。
- クラスタ転送はベストエフォート、共有サブスクリプションはノード単位。
- 永続化、拡張認証、送信エイリアス、ブリッジは未実装。
- 拡張にはソース変更が必要で、プラグインホストはまだありません。
