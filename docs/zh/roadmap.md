# 路线图

路线图代表方向，不是承诺。优先级取决于生产反馈与安全需求。

## 0.1 — 基础

- [x] MQTT 3.1.1 与 5.0（TCP、TLS、WebSocket、安全 WebSocket）
- [x] QoS 0/1/2、保留消息、遗嘱、会话过期
- [x] 共享订阅与 MQTT 5 订阅选项
- [x] 密码、JWT、匿名认证
- [x] 带身份占位符的有序主题 ACL
- [x] Gossip 成员管理与签名跨节点路由
- [x] REST API 与 Vue 3 控制台
- [x] CLI、Docker、Compose、Kubernetes、Helm
- [x] Prometheus 指标、健康探针、结构化日志

## 0.2 — 持久化与运维

- [x] 追加日志的文件保留消息存储（0.4.0）
- [x] 启动及文件增长时压缩日志（0.4.0）
- [x] 可恢复队列与订阅的持久会话快照（0.5.0）
- [x] 用于崩溃与全集群重启恢复的文件会话副本
- [ ] SQLite 与 PostgreSQL Provider
- [x] 保留消息与会话备份恢复（0.5.0）
- [x] 等待 inflight 确认的优雅 drain（0.5.0）
- [x] 按客户端与按来源 IP 的连接限流（0.3.0）
- [x] 每客户端消息速率配额（0.3.0）
- [x] 主题级发布配额（0.5.0）
- [ ] 发布与投递链路的 OpenTelemetry 追踪

## 0.3 — 协议深度

- [x] response-topic 请求/响应辅助（0.9.0）
- [ ] MQTT over QUIC 实验
- [x] 跨节点全局共享订阅协调
- [x] 集群保留消息墓碑与 last-write-wins（0.7.0）
- [x] 每客户端订阅标识上限

## 0.4 — 集成

- [x] 带过滤规则的 HTTP Webhook 桥接（0.10.0）
- [x] NATS 桥接模块（0.14.0）
- [x] Kafka 桥接模块（0.15.0，ADR 0007）
- [x] RabbitMQ 桥接模块（0.16.0，ADR 0008）
- [x] 路由动作：按主题过滤器 `drop` 与前缀 `rewrite`

## 明确的非目标

- 兼容第三方 Broker 私有插件 API。
- 复用第三方 Broker 的配置文件或控制台。
- 复制其他实现的源码、测试或文档。
- 声称获得任何 Broker 厂商的认证或背书。

## 如何影响路线图

请带上以下内容发起讨论：

- 工作负载（客户端数、消息速率、负载大小、保留时间）
- 部署目标（单机、Kubernetes、边缘）
- 需要消除的运维痛点
- 任何合规约束

安全修复始终优先于新功能。
