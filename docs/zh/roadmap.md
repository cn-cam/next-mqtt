# 路线图

路线图代表方向，不是承诺。优先级取决于生产反馈与安全需求。

## 0.1 — 基础

- [x] MQTT 3.1.1/5.0
- [x] TCP/TLS/WS/WSS
- [x] QoS 0/1/2、保留消息、遗嘱、会话过期
- [x] 共享订阅与 MQTT 5 订阅选项
- [x] 密码、JWT、匿名认证
- [x] 有序主题 ACL
- [x] gossip 成员与签名跨节点路由
- [x] REST API 与 Vue 3 控制台
- [x] CLI、Docker、Compose、Kubernetes、Helm
- [x] Prometheus、健康检查、结构化日志

## 0.2 — 持久化与运维

- [x] 文件追加日志的保留消息存储（0.4.0）
- [x] 启动及文件增长时压缩日志（0.4.0）
- [ ] 可插拔会话存储
- [ ] SQLite/PostgreSQL Provider
- [ ] 会话备份与恢复
- [ ] 优雅 drain（等待 inflight 确认）
- [x] 每客户端/每 IP 连接限流（0.3.0）
- [x] 每客户端消息速率配额（0.3.0）
- [ ] 主题级配额
- [ ] OpenTelemetry 追踪

- 兼容第三方 Broker 私有插件 API
- 复用第三方 Broker 配置/控制台
- 复制其他实现源码/测试/文档

安全修复始终优先于新功能。
