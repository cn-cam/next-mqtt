## 검증

현재 **125개 테스트** 통과(Core 63, Broker 49, Server 13). CI에서 빌드, 테스트,
대시보드, 문서, Helm/Kustomize, 이미지, CodeQL을 검증합니다.

## 알려진 제한

- 상태는 메모리 내에 있어 재시작 시 세션, 큐, retained가 사라집니다.
- 클러스터 전달은 최선 노력이며 공유 구독은 노드 단위입니다.
- 영구 저장, 강화 인증, 아웃바운드 별칭, 속도 제한, 브리지, 플러그인 SDK는 미구현입니다.
