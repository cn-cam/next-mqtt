# 로드맵

로드맵은 의도이며 계약이 아닙니다. 우선순위는 운영 피드백과 보안 요구를 따릅니다.

## 0.1 — 기반

- [x] MQTT 3.1.1과 5.0(TCP, TLS, WebSocket, 보안 WebSocket)
- [x] QoS 0/1/2, retained, 유언, 세션 만료
- [x] 공유 구독과 MQTT 5 구독 옵션
- [x] 비밀번호, JWT, 익명 인증
- [x] ID 자리표시자가 있는 순서 있는 토픽 ACL
- [x] Gossip 멤버십과 서명된 노드 간 라우팅
- [x] REST API와 Vue 3 대시보드
- [x] CLI, Docker, Compose, Kubernetes, Helm
- [x] Prometheus 지표, 상태 프로브, 구조화 로그

## 0.2 — 내구성과 운영

- [x] 추가 전용 저널을 쓰는 파일 retained 저장소(0.4.0)
- [x] 시작 시와 파일이 커질 때 저널 압축(0.4.0)
- [x] 큐와 구독을 복원하는 영속 세션 스냅숏(0.5.0)
- [x] 크래시와 전체 클러스터 재시작 복구를 위한 파일 세션 복제본
- [ ] SQLite와 PostgreSQL 제공자
- [x] retained와 세션 상태 백업/복원(0.5.0)
- [x] inflight 확인을 기다리는 정상 드레인(0.5.0)
- [x] 클라이언트별 및 IP별 연결 속도 제한(0.3.0)
- [x] 클라이언트별 메시지 속도 쿼터(0.3.0)
- [x] 토픽 단위 발행 쿼터(0.5.0)
- [ ] 발행과 전달 경로의 OpenTelemetry 추적

## 0.3 — 프로토콜 심화

- [x] 교체 가능한 제공자와 확장 인증(`AUTH`, 0.8.0)
- [x] 아웃바운드 토픽 별칭
- [x] response-topic 요청/응답 헬퍼(0.9.0)
- [ ] MQTT over QUIC 실험
- [x] 노드 간 전역 공유 구독 조정
- [x] 클러스터 인식 retained tombstone과 last-write-wins(0.7.0)
- [x] 클라이언트별 구독 식별자 한도

## 0.4 — 통합

- [x] 필터 규칙이 있는 HTTP webhook 브리지(0.10.0)
- [x] NATS 브리지 모듈(0.14.0)
- [x] Kafka 브리지 모듈(0.15.0, ADR 0007)
- [x] RabbitMQ 브리지 모듈(0.16.0, ADR 0008)
- [x] 라우팅 동작: 토픽 필터 drop과 접두사 rewrite
- [ ] 페이로드 보강과 스키마 검증
- [x] 매니페스트와 회수 가능 로딩을 갖춘 자체 플러그인 호스트(0.12.0)

  자체 확장 호스트입니다. 버전이 붙은 계약, 명시적 수명 주기, 이 프로젝트가 정의하는
  매니페스트를 사용하며 다른 벤더의 플러그인 API가 아닙니다.
  [ADR 0005](/adr/0005-extension-interfaces.md)와
  [기능 목록](features.md#확장성)을 참고하십시오.
- [ ] 페이로드 검증을 위한 스키마 레지스트리 훅
- [ ] 멀티테넌트 네임스페이스

## 명확한 비목표

- 다른 브로커의 사설 플러그인 API와의 호환성.
- 다른 브로커의 설정 파일이나 대시보드 재사용.
- 다른 구현의 소스, 테스트, 문서 복제.
- 브로커 벤더의 인증이나 권장 주장.

## 로드맵에 영향을 주는 방법

다음 내용을 담아 토론을 여십시오:

- 워크로드(클라이언트 수, 메시지 속도, 페이로드 크기, 보존 기간)
- 배포 대상(단일 노드, Kubernetes, 엣지)
- 해결하려는 운영 문제
- 컴플라이언스 제약

보안 수정은 항상 기능 작업보다 우선합니다.
